# Contributing

Start with a focused issue or patch explaining the real failure, expected behavior, and a synthetic reproduction. Preserve message identity and explicit partial/missing results. Do not collapse unknown senders into the current user or label a media path readable without validation.

Run the Windows test suite and `python scripts/check_release.py`. New fixtures must be fabricated or explicitly licensed public samples, never private chat exports. Keep external binaries and models out of commits. Avoid changes that silently broaden data access or start account/key scans on startup.

Changes are contributed under the repository's MIT license. Existing third-party notices must remain intact.
