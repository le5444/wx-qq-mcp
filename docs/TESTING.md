# 验证方法与边界

公开测试使用合成数据、临时目录、伪 MCP 子进程和 mock；不需要真实联系人、聊天数据库或模型。主要支持 Windows x64 / Python 3.12。

```powershell
python -m unittest discover -s unified_mcp -p 'test_*.py' -v
python scripts/check_release.py
python scripts/setup_voice.py --model sensevoice --plan
```

覆盖重点包括：

- 升序/降序合并、同秒排序、来源独立游标、查询条件绑定和明确终点。
- 同一服务器 ID 对应多个本地记录时的保留规则，未知发送者不猜测。
- 后端无响应、崩溃、取消、并发关闭、空闲退出及重启。
- 无账号配置时可以加载工具目录，运行数据不写入源码包。
- 损坏图像、动画帧、路径错配、错误内容摘要与歧义候选拒绝。
- 本地 OCR、长图分片、失败不缓存、临时文件清理。
- 本地 ASR 的音频身份、成功缓存、失败重试、自动识别标识及工作进程生命周期。
- 视频封面与真实视频文件区分、首帧探测、源文件保持。
- 表情下载域名/重定向/大小边界与内容校验。
- 模型安装计划无副作用、固定哈希与安全提取。
- QQ 数据库 keyset、兼容 offset、同秒复合排序、FTS-only记录、有限批次和深页；未知协议字段不作为已恢复正文。
- 精确消息 ID 歧义、按自然日读取、搜索后上下文、群统计触顶标为 partial，完整用户意图场景见 [SCENARIOS.md](SCENARIOS.md)。
- OS 文件锁下的并发缓存写入、损坏缓存拒绝、默认拒绝覆盖与原子发布。
- 快照每页事务提交、取消/截断后的恢复、源页变化拒绝、仅媒体可用性变化允许重试、单来源与QQ群工作流。
- 分阶段失败重试、模型版本变化、新语音补元数据、一条命令中断后完成最终阅读页。
- 100,000 条合成记录有序流归并的 Python 分配峰值上限测试；它不覆盖 SQLCipher 原生分配、完整进程或模型峰值。
- portable 阅读包整体搬移、相对媒体引用、分片浏览器离线加载、音频/图片/GIF与emoji显示。
- 共享后台协议转发、相同配置实例复用、连接生命周期及语音任务合并；部署时仍需真实双客户端验证。

总入口和文件格式说明见 [WORKFLOW.md](WORKFLOW.md)。不要用累计测试数量代替实际覆盖；每轮发布记录当时通过的测试与真实环境范围。

真实微信/QQ兼容性属于用户环境验收。建议先选择自己有权访问的一个小时间窗，核对双方身份、数量、方向、分页终点和媒体原件；再扩大范围。不要把某台电脑上的成功结果解释为所有微信/QQ版本均可用。

真实音频识别成功表示生成了文字，不能由此推导逐字准确率。图片像素解码成功、OCR有结果、视频首帧有效，也各自只说明相应层面。提交问题时只保留脱敏统计或合成复现。
